#  TechFile

**TechFile** es un portal moderno de descargas diseñado para ofrecer acceso rápido y directo a archivos, programas y recursos de software. Construido con React y Vite, garantiza una experiencia de usuario fluida, rápida y sin interrupciones.

---

##  Características Principales

* **Descargas Directas:** Enlaces limpios, sin publicidad ni acortadores molestos.
* **Buscador Dinámico:** Filtra e interactúa con el catálogo de archivos en tiempo real.
* **Categorías Organizadas:** Explora por Sistema, Drivers, Software y Herramientas.
* **Modales Inteligentes:** Vistas especializadas para distribuciones de Linux y paquetes de controladores.
* **Diseño Moderno:** Interfaz estilizada, oscura (dark mode) y totalmente responsive.

---

## 🛠️ Tecnologías Usadas

* **React** (Hooks: `useState`, `useEffect`)
* **Vite** (Entorno de desarrollo ultra rápido)
* **Vanilla CSS** (Variables, Flexbox/Grid, Animaciones)
* **HTML5 / JSX**
